# 205.2-Project-Development

***USER MANUAL****
For this project to succesfully run, the following requirements must be met to be able to succesfully open this project 

1. Create venv by navigating to the folder, "python -m venv venv",
2. Open "Command Line" via cmd in project folder and install Django - "pip install Django"
3. Install Flask "python -m pip install Flask"
4. Postgres Server must be activated via using the names that can be found in settings.py
5. Run project "python manage.py runserver"
